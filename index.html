unraid2mos

Convert Unraid Community Applications docker templates (XML) into MOS Hub docker templates (JSON), right in your browser. Nothing is uploaded anywhere - conversion runs entirely client-side.

Storage paths

Defaults to /mnt/cache, MOS's own documented standard pool path for published templates. Leave blank to use that default, or type a different pool name.

Templates
Runs the same conversion logic as the unraid2mos.py CLI script. See the README for details on what gets converted and why.
